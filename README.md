# java-lotto-precourse

### 로또 발행 프로젝트

해당 프로젝트는 간단한 로또 발매기를 구현하는 프로그램이다. 로또 번호의 범위는 1~45까지이며, 로또를 발행할 때는 중복되지 않은 6개의 랜덤 숫자를 뽑는다. 당첨 번호 추첨 시에는 중복되지 않는 숫자 6개와
보너스 번호 1개를 뽑는다. 사용자가 로또 구입 금액을 입력하면, 구입 금액에 해당하는 만큼 로또가 발행되고, 발행된 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임이 종료되도록 구현하는
프레젝트이다.

---

### 프로젝트 흐름

1. 로또 구입 금액을 1000원 단위로 입력받는다.
2. 입력값 검증 절차
    1. 앞뒤의 공백을 제거하고, 공백인지 확인한다. 공백이라면, 예외 처리한다.
    2. 정수가 입력되었는지 확인한다. 정수가 아닌 경우에는 예외를 처리한다.
    3. 정수의 범위가 Integer범위를 넘어갈 수 있으므로, 입력의 현실성을 고려해 범위는 Long 범위로 제한한다(약, 9경). 이를 초과할 경우 예외 처리한다.
    4. 양수가 입력되었는지 확인한다. 0 또는 음수가 입력된 경우에는 예외 처리한다.
    5. 1000원으로 나누어 떨어지는지 확인한다. 나누어 떨어지지 않는 경우, 예외 처리한다.
    6. 예외 처리가 된 경우, 사용자에게 오류 메시지를 출력하고, 유효한 금액이 입력될 때까지 반복하여 입력을 요청한다.
3. 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬해 출력한다
    1. 발행한 로또의 수량을 출력한다.
    2. 발행한 로또의 수량만큼, 랜덤 번호를 1~45의 숫자 중에서 중복되지 않게 6개를 오름차순으로 출력한다.
    3. 로또의 번호가 1~45 사이의 6개의 숫자인지 검증한다. 그렇지 않은 경우에는 예외 처리한다.
    4. 로또 생성 시 중복된 숫자가 존재하는 경우, 예외 처리한다.
    5. 예외 발생이 하면, 번호들을 전량 폐기하고, 정상적인 번호세트가 모두 생성될 때까지 재생성한다.
4. 사용자에게 당첨 번호를 입력받는다.
    1. 공백이 주어진 경우, 예외 처리한다.
    2. 당첨번호는 쉼표를 기준으로 구분한다.
    3. 쉼표 사이의 공백을 제거하고, 1~45사이의 숫자가 입력된 지 검증한다. 그렇지 않은 경우에는 예외 처리한다.
    4. 중복된 번호가 있는지 검증한다. 중복 번호 존재 시 예외 처리한다.
    5. 6개의 번호만 입력된 지 확인한다. 6개 초과 및 미만인 경우에는 예외 처리한다.
    6. 예외 발생한 경우, 사용자에게 다시 입력을 받는다.
5. 보너스 번호를 입력받는다.
    1. 공백이 주어진 경우, 예외 처리한다.
    2. 입력의 앞뒤 공백을 제거하고, 1~45 사이의 숫자가 입력된지 검증한다. 범위를 벗어난 경우 예외 처리를 한다.
    3. 당첨 번호 6개 중 어느 것과 중복되지 않아야 한다. 중복된 경우, 예외 처리한다.
    4. 예외 발생한 경우, 사용자에게 다시 입력을 받는다.
6. 당첨 내역을 출력한다.
    1. 몇개가 일치했는지와 수량을 출력한다.
7. 수익률을 출력한다. 수익률은 소수점 둘째 자리에서 반올림해, 소수점 첫째 자리까지 출력한다.
    1. 수익률 = **(획득한 금액 - 투자 금액) / 투자 금액** 으로 계산한다.

### 전체 실행 흐름 요약

1. 로또 구입 금액 입력 및 검증
2. 로또 번호 자동 발행 및 출력
3. 당첨 번호 입력
4. 보너스 번호 입력
5. 당첨 내역 계산 및 출력
6. 수익률 출력
